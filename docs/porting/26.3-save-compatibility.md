# Minecraft 26.3 save compatibility

Back up a Latitude world before opening it in Minecraft 26.3. Test important worlds through a
disposable copy first. Saving a world in 26.3 may update Minecraft data outside Latitude's control,
so downgrading that saved copy to 26.2 is unsupported.

## Dappled Forest in an existing world

A structurally valid 26.2 provider-ticket world receives one additive content-roster stamp when it
first opens with the 26.3 port. The world's original provider roster and biome-representation plan
remain unchanged. Latitude adds Dappled Forest only to the in-memory choices used while generating
new terrain.

- Explored chunks are never rewritten or regenerated.
- Newly explored, eligible cool-border terrain may contain Dappled Forest.
- Existing worlds do not receive a guaranteed Dappled Forest province. If all eligible territory
  was explored already, the biome may remain unavailable in that world.
- Loading the same world again does not add another copy of the biome.
- Worlds with an older policy, a missing or unreadable provider profile, incomplete V4 coverage
  state, an unknown roster revision, or damaged additions are left unchanged.

This upgrade does not add Abandoned Camps to custom biomes. Minecraft's own biome tags continue to
control the Dappled Forest camp variant.
